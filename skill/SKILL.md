# 小红书精华小书

一条链接进，一本小书出：**查重 → 采集 → 读图 → 精选 → 成稿 → 排版 → 验收 → 归档**。

**内容优先**是这套流程的第一原则：原文照录与来源是主角，编者文字只做极简交代。
每本书末尾自动带一页「联系与合作」二维码矩阵，读者可以加作者、打赏、谈合作、索取全套合集。

## 何时用

- 用户丢来小红书笔记链接 / 分享文案 / `xhslink.com` 或 `xhslink.cn` 短链，想把内容留成册子；
- 用户想把刷到的若干篇同主题帖子汇成一本合集；
- 用户强调「评论区也要」「图里的字也要」「要像小红书那样排版」。

## 依赖

- Python 3.9+，需要 `reportlab`、`pymupdf`、`fonttools`；
- 中文字体：宋体 / 黑体 / 楷体 / 仿宋（Windows 自带）；`curl`（采集）；
- **排版引擎自带**：`vendor/book_pdf.py`（含 `--preset xhs`、`@@CMT/@@STAR/@@CONTACT`），
  不依赖外部 `ebook-pdf-maker`；需要时可设 `XHS_BOOK_ENGINE` 覆盖；
- **品牌资源**：`assets/brand/brand.json` + 三张二维码图片。改联系页文案、换码只改这个目录，
  不用碰引擎和书稿（详见 `assets/brand/README.md`）。

环境自检：

```bash
python scripts/build_book.py --help
python -c "import reportlab, pymupdf; print('ok')"
```

## 八步流程

### 0 查重

```bash
python scripts/shelf.py check "<笔记链接 / 短链 / 裸 ID>"
```

已归档的先提示旧档位置，由用户决定调旧档或重制（`--v2` 保留旧版）。

### 1 采集

```bash
python scripts/collect_note.py "<笔记链接>" -o note/
```

产物：`note_data.json`（正文、作者、互动数、发布时间、话题标签、首屏评论及附图）、
`comments.md`（评论人读版）、`images/`（原帖图与评论图）、`page.html`（原始页面）。

要点：移动端 SSR 才有数据，脚本已固定 iPhone UA；公开页**仅首屏评论**可见（通常 5 条一级 + 部分回复），
不是全量、不是热度榜；`xhslink` 短链自动跟随跳转，被风控时可用 `--html` 离线解析。

### 2 读图（最容易漏的一步）

**逐张看图**，不要只看文件名。标题卡、观点卡、图表、时间线 → 收进书里并用 `@@PIC` 逐字转录图中文字
（`／` 按原断行，装饰元素不转录）；推广截图、带第三方水印的付费长图 → 不收，在末章交代数量与原因；
头像、UI 截图 → 忽略。

### 3 精选（内容优先）

- **原文**：全文照录，只重排分段；关键句 `==…==` 高亮，最锋利的半句 `**…**` 加粗。
- **评论区**：有信息量的可见评论应收尽收，一条评论 = 一张 `@@CMT` 卡；作者本人回复单独成卡。
- **精髓评论**：全书只抬 1–2 条为 `@@STAR`，同款卡加珊瑚红框，不另起一套特写。
- **金句**：`@@KEY 原句｜昵称`，句句自带署名，不许靠编者注事后补出处。
- **编者注**：只留「为什么值得留」的一句（≤20 字）或图版文字的一句说明（≤30 字）。
  归一化声明、可见范围、逐字比对口径、装饰元素处理、未选入理由等**元说明一律合并到末章说一次**。
- **不写占位文字**：赞数没返回就不写，不许出现「赞数未显示」。

### 4 成稿（四章，不是八章）

按 `FORMAT.md` 写纯 TXT，`templates/book_source_template.txt` 是可复制骨架：

1. **原帖**：配图 + `@@PIC` 图版文字 + 文字正文照录
2. **评论区 · 讨论线**：`@@H2` 分线，线下直接排 `@@CMT` / `@@STAR` 卡
3. **金句**：`@@KEY 原句｜昵称`
4. **出处与采集说明**：链接、时间、互动数、可见范围、归一化口径、版权声明，**全书只在这里说一次**

删掉「编者序」「观点拆解」「编者按」这类元章节，全书 `@@LEAD` 最多 1 条，不用 `@@PAGE` 制造空页。
**照录不改字**：不润色、不缩写、不改标点、不补句末标点；允许的三项归一化必须在此章逐项写明。

### 5 排版

```bash
python scripts/build_book.py --source note/book_source.txt \
  --title "书名" --author "原作者昵称" \
  --intro "一句话说明收了什么、仅供个人存档" -o note/书名.pdf
```

默认 `--preset xhs`（白底珊瑚红、黑体正文 10.4/17.6、版心更宽）。
也可 `--preset modern`；`classic` **仅限公版古籍**，当代内容禁用。

**联系页自动兜底**：书稿没写 `@@CONTACT` 时，`build_book.py` 会生成同目录临时副本补上标记再排，
排完删除；引擎从 `--assets assets/brand` 读 `brand.json` 渲染三码矩阵。所以每本书必然有联系页。
若引擎不含 `@@CONTACT` 或品牌资源缺失，脚本直接报错，不会静默出缺页的书。

### 6 验收

```bash
python scripts/verify_book.py --pdf note/书名.pdf --source note/book_source.txt \
  --data note/note_data.json --render note/抽样页
```

必须全 PASS，除原有项（残留标记、行首标点、引文逐字、版权口径、目录书签）外新增三项：

- **联系页二维码矩阵**：联系页存在、内嵌二维码图片数达标、`brand.json` 的 `must_contain` 逐项命中、
  且保留了「整理者 ≠ 原帖作者」的版权区分；
- **来源清晰度**：每条金句自带署名，来自评论的引用块前有署名行；
- **内容密度**（新格式书稿）：NOTE ≤8%、编者议论 ≤15%、出处说明 ≤35%、原文照录 ≥35%。

复核历史归档可加 `--no-contact` 跳过联系页检查，正常成书不许用。
最后用 `ViewImage` 看 2–3 张抽样页（含联系页），确认卡片不跨页、二维码清晰、插图不裁切。

### 7 归档（成书后必做）

```bash
python scripts/shelf.py archive <成书工作目录> --title "书名" --author "原作者" \
  --note-id "<笔记链接或ID>" --tags "标签,逗号分隔" --brief "一句话简介" \
  --pdf 成品.pdf --source book_source.txt --data note_data.json --verify 验收日志 \
  --render 抽样页
python scripts/shelf.py list
```

书架根目录默认 `C:\Users\无相道一\WorkBuddy\xhs-library\`（`--root` 可改）：
`INDEX.md` 总目录 + `skill/` 工具包 + `books/日期_书名_作者/` 每本全套归档。
同一笔记再次 archive 会被拦下；重制加 `--v2`（旧版保留）。
**`books/` 与 `INDEX.md` 只在本地，不进公开仓库**——书的内容含他人原创。

## 书稿标记速查

`@@CMT 来源｜原文｜短评` 评论卡 · `@@STAR 来源｜原文｜短评` 精髓卡（珊瑚红框）·
`@@KEY 原句｜昵称` 金句自带署名 · `@@PIC 图里的文字` 图版文字（`／` 分行）·
`@@IMG 路径 | 图注` 插图 · `@@QUOTE` 原帖正文/图注引用块 · `@@BY` 评论署名（旧格式）·
`@@H2` 小节 · `@@NOTE` 编者注（自动加「编者注｜」）· `@@LEAD` 核心观点 · `@@POINT` 分点 ·
`@@CAP` 小字 · `@@RULE` 分隔线 · `@@PAGE` 分页 · `@@CONTACT` 联系页（可不写，自动补）；
行内 `**重点**`（珊瑚红加粗）、`==重点==`（淡黄高亮）。

## 硬规则

1. **三种身份不混**：原文照录 / 他人评论 / 编者文字，样式与板块永不串用。
2. **引文逐字**：评论与金句必须能在 `note_data.json` 里逐字命中，标点也不许改；金句句句带署名。
3. **内容优先**：原文照录 ≥35%，编者注 ≤8%；元说明全书只在末章说一次，同一句话不许重复出现。
4. **图片要有交代**：收了的图给图注与图版文字；没收的图说明原因与数量。
5. **来源三要素**：谁说的、多少赞、什么关系；拿不到的数据留白，不写「未显示」占位。
6. **每本必有联系页**：`assets/brand/brand.json` 与三张二维码必须齐备；页脚必须保留
   「扫码联系的是整理者，非原帖作者」的区分，不许把引流信息混成原作者署名。
7. **版权口径**：当代内容一律 `xhs` 或 `modern`；写明「著作权归原作者及评论作者所有，仅供个人阅读存档，请勿传播或商用」。
8. **不编数据**：拿不到的发布时间、互动数、图片一律留白并说明，不推测、不补写。
9. **查重在先、归档在后**：成书前 `shelf.py check`，验收通过后 `shelf.py archive` 更新 INDEX.md；`books/` 不进 git。

## 目录

```
xhs-essence-book/
├── SKILL.md                          本文件
├── FORMAT.md                         书稿格式语言（标记、四章规范、硬上限、验收清单）
├── README.md                         安装与仓库说明
├── templates/book_source_template.txt 四章书稿骨架
├── assets/brand/                     品牌资源：brand.json + 三张二维码 + README
├── vendor/book_pdf.py                排版引擎（含 xhs preset、评论卡、联系页）
└── scripts/
    ├── collect_note.py               采集（SSR 解析 + 图片落地 + 评论导出）
    ├── build_book.py                 排版（默认 xhs，自动补 @@CONTACT）
    ├── verify_book.py                验收（含矩阵、来源、内容密度）
    └── shelf.py                      书架归档（init/archive/list/check）
```
