# 精华小书 · 书稿格式规范（v2.1 · 内容优先 + 紧凑密度）

> 一份书稿同时是两样东西：**TXT 是可读的纯文本**，**PDF 是同一份稿子的渲染升级**。
> 只在行首用 `@@` 标记内容身份，不塞样式代码；换渲染器、换开本、换主题，稿子不用重写。
>
> **v2 的改动**：从「编辑工作报告」回到「原文卡片册」——四章结构、评论卡自带来源、
> 金句句句署名、编者注按字数硬上限约束，并新增固定联系页 `@@CONTACT`。
>
> **v2.1 的改动**：默认紧凑密度模式（`--density dense`），字号行距与卡片间距收紧、
> 出版说明与目录合并、二维码矩阵成为真正尾页；章节拆细到「一章一页」，
> 评论区讨论线可以按线拆成多章——**拆章不删评论**，页数靠密度与结构控制。

## 一、四条不可让渡的原则

1. **身份优先于美观**。读者必须一眼看出某段是「原文照录」「他人评论」还是「编者文字」，三者样式永不混用。
2. **照录不改字**。只在标记内加行内重点，不润色、不缩写、不改标点、**不补写句末标点**。
   允许的归一化只有三项：略去平台表情代码与字体不支持的表情符号、合并换行、统一引号样式；
   三者必须在末章逐项写明。原帖评论常以表情代码或无标点收尾，照录就照录到那里为止。
3. **提炼必须可追溯**。核心观点、按语都是编者归纳，与原话分栏呈现，不得新增原文没有的事实。
4. **内容优先于说明**（v2 核心）。原文与来源是主角，编者文字只做极简交代。
   元说明（归一化声明、可见范围、逐字比对口径、装饰元素处理、未选入理由）
   **全书只在末章说一次**，同一句话不许在多个章节重复。验收脚本会量化卡住超标稿子。

## 二、内容身份与板块对照

| 内容身份 | 书稿写法 | PDF 里 |
|---|---|---|
| 章 | `第X章 标题` | 居中大标题 + 目录书签 |
| **评论卡（主力板块）** | `@@CMT 来源｜原文｜短评` | 浅粉底 + 珊瑚红左条：顶部灰色来源行、大字原文、可选一句短评，整卡不跨页 |
| **精髓评论** | `@@STAR 来源｜原文｜短评` | 同款卡加珊瑚红细框，全书只 1–2 条 |
| **金句** | `@@KEY 原句｜昵称` | 朱红黑体原句 + 右对齐灰色小字署名，二者绑成一组不拆页 |
| 图注 / 原帖正文的引用 | `@@QUOTE 文字` | 浅灰底引用块（**不是评论**，不需要 `@@BY`） |
| 图里的文字 | `@@PIC 文字`（`／` 表示图内换行） | 细框卡片 + 「图 版 文 字 · 照 录」标签 |
| 插图 | `@@IMG 路径 \| 图注` | 等比居中 + 图注，图与图注不拆页 |
| **联系页** | `@@CONTACT` | 固定尾页：标题 + 说明 + 三码横排矩阵 + 品牌行 + 页脚声明 |
| 节内小标题 | `@@H2 文字` | 黑体左对齐 |
| 核心观点 | `@@LEAD 文字` | 卡片（全书最多 1 条，能不用就不用） |
| 编者按语 | `@@NOTE 文字` | 灰色小字 + 自动「编者注｜」前缀 |
| 分点 / 小字 / 分隔 / 分页 | `@@POINT` / `@@CAP` / `@@RULE` / `@@PAGE` | 列表 / 居中小字 / 细线 / 分页 |
| 普通正文 | 直接写 | 宋体两端对齐、首行缩进（新格式里**只会是末章出处说明**） |

行内标记：`**重点**` → 珊瑚红黑体加粗；`==重点==` → 淡黄底色高亮。
TXT 里看得见标记字符，PDF 里只留视觉效果；照录段落用这两个标记标重点，不算改字。

**兼容**：旧格式 `@@BY → @@QUOTE / @@GEM`、`@@LEAD`、`@@POINT` 仍能渲染，
但新书一律用 `@@CMT / @@STAR`，旧格式不参与内容密度硬校验。

## 三、组合规则（最容易做乱的部分）

**评论卡三段式**：`来源｜原文｜短评`，用全角竖线 `｜` 分隔，第三段可省略。

- 来源行写清三件事：**谁说的**（昵称）、**关系**（一级评论 / 回复谁 / 作者本人）、**分量**（赞数、回复数）。
  采集没返回的数据**直接留白**，不许写「赞数未显示」「未知」这类占位文字。
- 原文逐字照录，不改标点、不补句末标点；一张卡只放一条评论。
- 短评 ≤20 字，只写「为什么值得留」；写不出理由就不写，不要凑字。
- `@@STAR` 前同样写清来源，并在来源或短评里点明它推进/校正了什么。不要把高赞自动等同于精髓。

**金句必须自带出处**：`@@KEY 原句｜昵称`。
验收会逐句检查 `｜`；**禁止**用一条编者注事后补「第 3 句来自…第 4 句来自…」。
署名可以写「原帖配图」「图版文字」等来源性质，不一定是人昵称。

**联系页是固定尾页**：

- `@@CONTACT` 通常**不必写进书稿**——`build_book.py` 检测不到就自动生成临时副本补上，排完删除。
  写了也生效，位置应在全书最后。
- 文案与三张二维码全部来自 `assets/brand/brand.json`，改文案只改配置，不改书稿和引擎。
- 页脚必须保留「扫码联系的是整理者，非原帖作者」这一区分：书内正文是他人原创，
  引流信息不能让读者误以为是原帖作者的联系方式。
- 语气是**一则说明**，不是硬广：不写促销话术、不重复堆码、不夸大合集内容。

**图片里也有内容**：

- 图里能读出来的字一律 `@@PIC` 逐字转录，`／` 按原断行；装饰元素不转录，在末章一并交代。
- 图片是否收进书里看它是不是内容；推广截图、带第三方水印的付费长图不收也不转录。
- 转录必须说明来源：原帖配图还是某条评论的附图（写清谁的回复、尺寸）。

**视觉层级**：`@@STAR` > `@@LEAD` > `@@KEY` > `@@PIC` > `@@CMT` > `@@QUOTE` > `@@NOTE` > 正文。
一页里最多一个高阶板块，否则「重点」就不再是重点。

## 四、四章结构（SOP）

| 章 | 放什么 | 不放什么 |
|---|---|---|
| 一 · 原帖 | 配图、图版文字、文字正文照录 | 编者序、写作缘起 |
| 二 · 评论区 | `@@H2` 分讨论线，线下直接排 `@@CMT / @@STAR` | 长篇「为什么这样选」的说明 |
| 三 · 金句 | `@@KEY 原句｜昵称` | 事后补出处的编者注 |
| 四 · 出处与采集说明 | 链接、时间、互动数、可见范围、归一化口径、图片取舍、版权声明 | 重复前面已说过的话 |

流程：查重 → 采集 → 读图 → 精选 → 成稿 → 排版 → 验收 → 归档。
四章是**最小结构**，不是章数上限：第二章的讨论线若超过一页容量，就按讨论线
拆成「第二章 · 反对赋魅」「第三章 · 逃避责任」「第四章 · 经验误读」等，
金句章与出处章顺延（v3 实测 5 章 / 7 页，每章 1 页）。
`@@LEAD` 全书最多 1 条，不用 `@@PAGE` 硬造空页。

**紧凑密度版（v2.1 默认）的容量参考**：A5 一页约放 8–10 张 `@@CMT` 卡；
或 1 张 `@@IMG` 插图 + `@@PIC` 图版文字 + 2–3 张评论卡；或 9 条 `@@KEY` 加末章出处说明。
写稿时按这个容量估章，超过就拆章，**不要靠砍评论来压页数**。
`--density normal` 可还原 v2.0 的宽松版式，但同样内容会多出 3–4 页。

## 五、硬性量化上限（验收脚本会卡）

按书稿字数统计，新格式（含 `@@CMT` / `@@STAR`）启用：

| 指标 | 上限 / 下限 | 为什么 |
|---|---|---|
| `@@NOTE` 编者注 | ≤ 8% | 元说明是最主要的稀释来源 |
| 编者议论（NOTE+LEAD+POINT+CAP+H2+短评+章标题） | ≤ 15% | 议论不能盖过原文 |
| 出处说明（普通正文） | ≤ 35% | 必要元信息只留末章一份 |
| **原文照录** | **≥ 35%** | 书的主角必须是原话 |
| 金句署名覆盖率 | 100% | 来源必须跟着文字走 |
| 联系页二维码 | 3 张 + `must_contain` 全命中 | 每本书必有 |

参考实测（《一段无脑感慨》）：改版前编者/说明类 77.8%、原文 14.8%、19 条编者注 1440 字，
「非全量非热度排序」重复 5 次；改版后原文 44.5%、来源 22.6%、编者议论 8.4%、
出处说明 24.5%、NOTE 2.6%，页数 14 → 10，**原文绝对字数反而从 583 涨到 633**。
v2.1 紧凑增补版进一步到 **7 页 / 5 章 / 每章 1 页**，同时把可见评论从 11 条补齐到 17 条、
金句从 7 条增到 9 条，原文占比 41.4%（下限 35%）——页数下降与内容增加可以同时成立。

## 六、其他硬规则

- 排当代非公版内容**必须** `--preset xhs` 或 `modern`；`classic` 会写「原书著作权已入公有领域」，是错误的版权声明。
- 只拿到首屏评论时，末章写明「非全量、非热度排序」，不许包装成热评榜。
- 图注、`@@IMG` 路径、`@@CMT` 来源行里不要含 `<` `>` `&`。
- 评论区上传图片若来源/授权不明，不收录，并在末章交代数量与原因。
- 摘录含他人原创图文，默认仅供个人存档；公开传播需授权，书里按此口径标注。

## 七、验收清单

- [ ] 四章结构，元说明只在末章出现一次，同一句提示没有重复
- [ ] 每条 `@@CMT / @@STAR` 都有来源行；拿不到的数据留白、无占位文字
- [ ] `@@STAR` 全书 ≤2 条；`@@LEAD` 全书 ≤1 条
- [ ] 每条 `@@KEY` 都带 `｜署名`；来自评论的 `@@QUOTE` 前有 `@@BY`
- [ ] 引文与采集原文逐字比对通过（含图版文字语料）
- [ ] 联系页存在：3 张二维码清晰、`brand.json` 的 `must_contain` 全命中、页脚区分整理者与原帖作者
- [ ] 内容密度四项全部达标
- [ ] PDF 搜不到 `@@`、`**`、`==`、占位提示；无行首中文标点、无方框乱码
- [ ] 目录书签数与章数一致；插图完整、卡片不跨页、无「公版 / 国学经典」残留
- [ ] **全页样张**目视：无整页空白、无章节横跨 3 页以上、无卡片孤零零跨页、尾页即二维码矩阵
- [ ] 抽样页目视（含联系页）通过；`shelf.py archive` 归档并更新 INDEX.md
