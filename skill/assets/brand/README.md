# 品牌资源 · 二维码矩阵

每本 PDF 的末尾都会自动追加一页「联系与合作」：三张二维码横排 + 一小段说明 + 品牌行。
**改文案只改 `brand.json`，换二维码覆盖同名图片即可，不用碰排版引擎和书稿。**

| 文件 | 用途 |
|---|---|
| `brand.json` | 标题、说明文字、三码标签、品牌关联行、页脚声明、验收关键词 |
| `qr_weixin.jpg` | 冷石 · 微信（紫蓝渐变、中央微信图标） |
| `qr_huangjinchen.jpg` | 老哥 · 黄金臣（中央金字 logo） |
| `qr_lengshi_miaowu.jpg` | 冷石妙悟 · 模因公社（中央深灰 logo） |

## brand.json 字段

- `title` / `intro` / `paragraphs`：标题、引导句、说明段落（克制叙述，不写促销话术）
- `qr[].file|label|hint`：图片文件名、码下标签、标签下的一行小字；三码横排等宽
- `brand_line`：品牌关联行，珊瑚红居中小字
- `footer`：页脚声明。**必须保留「整理者 ≠ 原帖作者」的区分**，书内正文是他人原创，版权口径不能含糊
- `verify.must_contain`：验收脚本会逐项检查这些文字是否真的落在 PDF 里；改文案后同步更新

## 注意事项

- 二维码图片请保留四周白边（quiet zone），否则扫码成功率会下降
- 图片建议正方形、≥600px；PDF 里按约 100pt 等比缩放，原图分辨率会被保留
- 这个目录属于**工具资产**，会随 skill 一起进公开仓库；书籍内容（`books/`）不公开
- `build_book.py` 会把本目录路径传给排版引擎；书稿里没有写 `@@CONTACT` 时也会自动补上，保证每本都有
